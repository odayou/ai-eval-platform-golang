# AI Eval Platform — 部署指南

## 单二进制部署（推荐）

```bash
# 1. 构建前端
cd web && npm install && npm run build && cd ..

# 2. 构建后端(自动内嵌前端)
go build -ldflags="-s -w" -o server ./cmd/server/

# 3. 运行
./server

# 4. 访问 http://localhost:8080
```

二进制文件约 39MB，自带全部前端页面。

## Docker 部署

```bash
# 构建并启动
docker compose up -d

# 查看日志
docker compose logs -f

# 停止
docker compose down
```

## Nginx 反代部署

见 `deploy/nginx.conf`。

## 生产环境建议

1. **设置 GIN_MODE=release** — 关闭调试日志
2. **设置 DB_PATH** — 指定数据库路径
3. **配置 API Key** — 在设置页填写真实 Key
4. **开启 Docker 沙箱** — 设置 `DOCKER_ENABLED=true`
5. **配置反向代理** — 使用 nginx 处理 HTTPS
6. **定时备份数据库** — `data/eval.db` 为单文件，直接拷贝即可
