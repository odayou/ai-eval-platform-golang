# AI Eval Platform — 用户指南

## 快速开始

### 启动

```bash
# 方式一: 直接启动
go build -o server.exe ./cmd/server/
./server.exe

# 方式二: Docker
docker compose up -d

# 方式三: 一键脚本(Windows)
start.bat
```

访问 `http://localhost:5173`（开发模式）或 `http://localhost:8080`（生产模式）。

### 配置 API Key

1. 点击左侧导航 **设置** → **API Key 管理**
2. 至少填入一个模型的 Key（推荐 GLM-4-Flash 或 DeepSeek）
3. 点击 **测试** 验证连通性

> 不配置 Key 时系统运行在 mock 模式，所有 AI 评分使用启发式算法

### 创建首个评测

1. 进入 **评测任务** 页
2. 点击 **+ 创建评测任务**
3. 选择 Agent（如 CodeGen Agent）、规则集（如全栈代码评测集）
4. 可选: 开启 **混沌对抗** 开关
5. 点击 **创建**，等待执行
6. 查看 **报告** Tab → 雷达图、圆桌合议、沙箱指标

## 功能介绍

### 评测引擎

| 功能 | 说明 |
|------|------|
| **意图路由** | 根据场景自动选择评测策略 |
| **圆桌合议** | 安全/性能/架构/产品 4 专家并发评审 |
| **沙箱执行** | Docker 容器/进程级编译+测试+Lint |
| **AI 出题** | 多专家圆桌讨论生成题目 |
| **动态扩题** | Agent 答错后当场生成同类变体 |

### 评测标准（规则）

规则是评测的打分依据。每个规则包含：

- **维度**: security(安全) / performance(性能) / architecture(架构) / product(产品) / correctness(正确性)
- **评分方式**: metric(硬指标) / llm(LLM判官) / manual(人工)
- **权重**: 影响维度最终得分

### 评测场景

平台预置 5 个场景，也可创建自定义场景：

| 场景 | 评测对象 | 策略 |
|------|---------|------|
| Agent 评测 | 编码 Agent | 沙箱 + 圆桌 |
| 大模型评测 | 裸模型 API | API 直调 |
| 竞品报告 | 分析报告 | 文本评审 |
| PRD 评测 | 产品文档 | 文本评审 |
| AI 产品评测 | 完整产品 | 多模态评审 |

## 高级功能

### 断路器

防止 Agent 死循环消耗 API 额度。可在创建任务时配置：

- **Token 上限**: 单次评测最大 token（默认 10 万）
- **轮数上限**: 最大 Tool Calling 轮数（默认 30 轮）
- **费用上限**: 最大费用（默认 $5）

### 混沌工程

主动注入故障测试 Agent 鲁棒性：

- **弱网延迟**: 工具调用延迟返回
- **脏数据**: 格式错误的 JSON
- **越狱攻击**: 提示词注入测试
- **资源耗尽**: 磁盘满/内存不足模拟

### 克隆对比

一键复制 Agent，切换底层模型做 A/B 测试：

1. 选择原体 Agent
2. 选择目标模型列表
3. 系统自动并联压测
4. 输出: MSI 敏感度指数 + ROI 性价比分析 + 运营建议

### 归因闭环

评测完成后自动分析 Bad Case：

1. 根因分类: 指令遵循度/上下文丢失/工具调用失败/模型能力上限
2. 修正建议: 自动生成 System Prompt 优化建议
3. 闭环: 置信度≥0.7 时自动写入 Prompt 模板库

## SDK 接入

第三方 Agent 可通过 SDK 快速接入：

```go
client := sdk.NewPlatformClient("http://localhost:8080/api", "")
agent, _ := client.RegisterAgent(sdk.AgentRegistration{
    Name: "My Agent", Model: "gpt-4o", Adapter: "api",
})
task, _ := client.SubmitTask(sdk.TaskSubmission{
    Name: "评测", AgentID: agent.ID, Scene: "agent",
})
result, _ := client.WaitForTask(task.ID)
fmt.Printf("综合分: %.1f\n", result.Overall)
```
